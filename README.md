# Way To Learn AI

WAY ESTUDANTES AI

Plataforma Académica Inteligente para Estudantes de Moçambique

DESCRIÇÃO

Way Estudantes AI é uma plataforma educacional baseada em Inteligência Artificial destinada a estudantes do ensino secundário e superior em Moçambique. A plataforma ajuda os estudantes na realização de trabalhos para casa, resolução de exercícios, pesquisas académicas, testes, exames e produção de documentos académicos.

REGISTO DE USUÁRIOS

Todos os utilizadores devem efetuar o registo através dos seguintes campos obrigatórios:

* Nome
* Apelido
* Número de telefone de Moçambique
* E-mail
* Nível de ensino

  * Ensino Secundário
  * Ensino Superior
* Foto de perfil ou Emoji

PROCESSO DE REGISTO

1. Registo da conta
2. Escolha do nível de ensino
3. Verificação do e-mail através de código enviado para o Gmail
4. Adicionar foto de perfil ou emoji
5. Conclusão do registo
6. Acesso ao Chat AI

CHAT AI

O sistema oferece assistência académica para:

* Trabalhos para casa
* Exercícios
* Pesquisas
* Resumos
* Explicações de matérias
* Testes
* Exames
* Trabalhos académicos
